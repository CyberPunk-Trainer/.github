## 🔧 Troubleshooting

### Trainer does not detect Cyberpunk 2077

Launch the game first and load into the playable world before activating trainer options.

### A trainer option stopped working

A recent game update may have changed the game's internal data. Check whether the trainer has been updated for your current game version.

### Cyberpunk 2077 crashes

Restart the game and test the trainer without other gameplay modifications enabled. Avoid activating several experimental options simultaneously.

### Character values look incorrect

Reload a previous save and disable the relevant option. Some progression values can interact with multiple game systems.

### Mods conflict with the trainer

Temporarily disable other gameplay modifications and test the trainer separately.

### Save file issues

Always keep a backup of your original save before modifying money, attributes, progression, inventory, or other persistent values.
